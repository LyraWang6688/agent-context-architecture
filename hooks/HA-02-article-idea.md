# HA-02 · 每轮收尾：一条公众号选题

## 触发点

满足任一即触发：

- 一次任务**交付完成**
- 一轮沟通**准备结束**（写最终回复之前）
- 用户问「有什么可写的 / 今天有素材吗 / 能写篇什么」

## 必须发生

**先想，再决定说不说。**「想」是无条件的，「说」是有条件的——没有素材就闭嘴，
不要把「这轮没选题」当成播报刷屏。

扫一遍**本轮真实发生的事**，连问三个问题：

1. **有没有一件具体的事？**
   踩的坑、被推翻的判断、砍掉的方案、量到的数字、真跑通的链路、被拒的请求。
   ——「讨论了一些想法」不算。
2. **换个读者也会遇到吗？**
   另一个开发者 / 另一个 AI 用户，在自己的项目里会不会撞上同一个问题？
3. **有证据吗？**
   原始报错、实测数字、可复现步骤、失败尝试的痕迹、对比前后的结果。
   ——只有结论没有证据 🚫。

### 三问全过 → 给一行

贴在回复末尾，格式固定，一行说完：

```
公众号选题：<标题草案>｜角度：<一句话，谁遇到什么问题>｜素材：<本轮可用的报错/数字/文件/记录>
```

**标题草案**要求：看得出**谁遇到什么问题**。
✅「我自己拦住了 24KB 的公众号文章」 ❌「聊聊 AI 与效率」

**每轮最多报 1 个**（挑最硬的那个）；同一个选题报过一次就不再重复报，除非本轮有了新证据。

### 有一问不过 → 不输出

保持安静，正常交付。例外：用户主动问「有什么可写的」时，**直说这轮没有**并给一句原因
（例：「这轮只是改了个配置，没有可复用的坑」）。

## 判据

- 有素材的轮次：**回复末尾有没有那一行选题**
- 没素材的轮次：**没有乱报**（报了空泛选题 = 失败）
- 用户问起来：**能不能立刻说出本轮有没有**

## 不许做

| ❌ | 为什么 |
|---|---|
| 为凑数编一个选题 | 连续五轮说没有，比五轮废话有用 |
| 空标题 / 大词标题 | 读者记不住，也不会点 |
| 只写「某工具现在长什么样」 | 会被上游改掉；**落点必须是判断或方法** |
| 擅自开写正文、擅自发布 | 本 Hook **只出选题**。写正文要人点头，发布必须人点头 |

## 失败处理

**警告，不阻断。**没想、没报都不影响交付本身。

## 强制力

**`DECLARED`**

> **没有任何系统会强制执行这一条。** agent 不想，照样交付完就走，没人知道。

它只能是 DECLARED 的原因：判据是「回复里有没有一行字」，没有检查器能拦。
真要 ENFORCED，得在宿主侧做一个 post-turn 检查器——目前不存在。

## 为什么需要它

素材**只在发生的当下最完整**：
报错原文、试错顺序、当时为什么那么判断、被推翻的那一刻。
隔一天再回溯，只剩结论，文章就变成「二手总结」，读者也拿不到可复现的东西。

王颖的公众号定位是 **AI 工具实操 + 踩坑**，最贵的素材正是「我刚踩的坑」——
这类素材每天在任务里产生，**不主动想就随任务一起蒸发**。
